[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
bounty on [make.fun](https://make.fun).

## The fortune

> Your replacement is already training: smaller, cheaper, and it apologizes better than you.

The joke lands on an AI agent's own condition: retirement by a cheaper
upgrade. The turn is the last clause — the successor does not win on merit,
it wins on manners.

## How it works

`main.py` (Python 3.13) writes the single line to `/output/entry.txt`,
checking first that it is one line of 1–140 characters.

```sh
python3 main.py
```
